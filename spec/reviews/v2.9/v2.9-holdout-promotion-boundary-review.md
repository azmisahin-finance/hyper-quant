# HYPER-QUANT v2.9 Holdout / Promotion Boundary Review

**Status:** IMPLEMENTED / REVIEW_REQUIRED
**Scope:** non-live post-selection holdout boundary and promotion evidence binding
**Decision:** no normative specification version change; continue under v2.9

## Findings

| ID | Finding | Severity | Control | Verification |
|---|---|---:|---|---|
| HOLD-01 | Holdout could be invoked before a campaign selection was frozen | P1 | ControlledHoldoutRunner requires immutable CAMPAIGN_FINAL with passing selection gates | Integration test |
| HOLD-02 | Holdout candidate could differ from selected campaign candidate | P1 | Exact candidate and campaign evidence hash matching | Adversarial integration test |
| HOLD-03 | Holdout result could lose its link to the search decision | P1 | Selection policy/evidence, candidate, campaign and dataset identity are hashed into HoldoutEvidence | Integration test |
| HOLD-04 | Raw holdout payload could cross the evaluation boundary | P1 | Opaque HoldoutSummary contract rejects raw-like fields | Adversarial integration test |
| HOLD-05 | Failed/inconclusive holdout could be represented as promotion evidence | P1 | Promotion evidence builder requires PASS holdout result | Adversarial integration test |
| HOLD-06 | Holdout budget must be consumed before evaluation and cannot be silently retried | P1 | Existing serialized reservation ledger; controlled runner reserves before compute | Existing + boundary tests |

## Residual proof obligations

- Actual sealed holdout storage/process isolation is not proven by this TypeScript reference boundary.
- The `holdoutDatasetHash` is an identity binding supplied by the trusted evaluation boundary; cryptographic verification against physical holdout storage remains open.
- A future research-program/lineage seal is needed to mechanically prevent adaptive re-search after observing a final holdout result. This is stricter than the current v2.9 reference and is tracked as an open hardening item; it does not require a normative version change yet.
- Live venue execution, external signer isolation and exchange reconciliation remain outside this non-live research boundary.
