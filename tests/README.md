# Tests

The test suite shall eventually include:

- deterministic unit tests,
- property/invariant tests,
- replay/backtest reproducibility tests,
- exchange-adapter contract tests,
- fill/partial-fill tests,
- reconciliation tests,
- kill-switch tests,
- repeated-loss escalation tests,
- research-trial registration enforcement tests,
- AI isolation tests,
- upper-plane chaos scenarios,
- end-to-end canary safety tests.

No production promotion should rely solely on happy-path tests.
